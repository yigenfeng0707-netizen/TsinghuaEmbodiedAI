Add JCIIOT full source code + GitHub Actions CI + reproducibility tooling

Adds the complete JCIIOT source tree (1066 files, selective copy excluding
large binary assets), continuous integration workflows, and reproducibility
support files.

Source code (JCIIOT/):
- src/robot_agent/: main application (skills, core, environments, types)
- robomimic/: BC training framework fork (algo, config, envs, models, scripts)
- robosuite/: robosuite fork (controllers, environments, models, renderers)
- knowledge/: task_config.json (single source of truth), SOPs, robot_params
- tools/: debugging and deployment utilities
- tests/: unit tests
- recordings/: regression and robustness test results
- new/: factory_sorting.py and siemens_arena.py environment definitions

Continuous integration (.github/workflows/):
- latex.yml: auto-compile paper/main.tex on paper/** changes
- python-syntax.yml: py_compile check on Python 3.10/3.11/3.12
- codeql.yml: weekly security scan

Reproducibility:
- scripts/download_models.py: checkpoint and demo data fetch helper
- requirements.txt: pip dependencies (pinned versions)
- environment.yml: conda environment spec
- .python-version: 3.12
- CITATION.cff: citation metadata (GitHub will render "Cite this repository")

Issue templates (.github/ISSUE_TEMPLATE/):
- bug_report.md
- leaderboard-submission.md

Excluded via .gitignore: *.pth, *.hdf5, *.obj, *.stl, *.msh, *.png, *.log,
__pycache__/, .trae/, .env, JCIIOT/robosuite/dataset/ (large binary assets).
